# КА-ШИ-РА ВЕСТНИК — сайт-киоск

Структура для публикации газеты выпусками: каждый номер — отдельная папка, на главной — киоск со всеми выпусками.

```
kiosk/
├─ index.html              ← киоск (главная страница, список выпусков)
├─ README.md               ← этот файл
├─ .nojekyll               ← отключает обработку Jekyll на GitHub Pages
├─ issues/
│  └─ issue-1/
│     ├─ index.html        ← сам выпуск №1 (газета)
│     ├─ cover.jpg         ← обложка для карточки в киоске
│     └─ assets/comic/     ← иллюстрации выпуска
└─ template/               ← болванка для следующего номера
   ├─ index.html
   ├─ README.txt
   └─ assets/comic/
```

---

## 1. Как добавить новый выпуск

1. Скопируй папку `template/` и переименуй копию в `issues/issue-2/` (далее — `issue-3`, `issue-4` и так по порядку).
2. Положи в неё свою газету как **`index.html`** (имя именно такое — иначе не откроется по ссылке).
3. Иллюстрации положи в `issues/issue-2/assets/comic/`, и в `index.html` ссылайся на них так: `assets/comic/имя.jpg`.
4. Сделай обложку: открой газету в браузере, сделай снимок верхней части и сохрани как `issues/issue-2/cover.jpg` (ширина ~800 px, высота ~900–1400 px).
5. Открой корневой `index.html` и добавь вторую карточку в блок `<div class="grid">` — скопируй существующую и поменяй четыре места: номер, дату, описание и ссылку.

Образец карточки:

```html
<a class="card" href="issues/issue-2/index.html">
  <img class="thumb" src="issues/issue-2/cover.jpg" alt="Обложка выпуска №2">
  <div class="body">
    <div class="no">Выпуск №2</div>
    <div class="date">октябрь 2026</div>
    <p class="desc">Короткое описание номера — одна-две фразы.</p>
    <div class="go">Читать выпуск →</div>
  </div>
</a>
```

## 2. Как задеплоить на GitHub Pages

Разовая настройка:

1. Создай публичный репозиторий, например `kashira-vestnik`.
2. Загрузи **содержимое** папки `kiosk/` (файл `index.html`, папки `issues`, `template`, `.nojekyll`) — через **Add file → Upload files** можно перетащить всё сразу.
   Важно: грузить надо содержимое, а не саму папку `kiosk` — `index.html` должен оказаться в корне репозитория.
3. **Settings → Pages** → Source: `Deploy from a branch` → Branch: `main`, папка `/ (root)` → **Save**.
4. Через 1–2 минуты сайт откроется по адресу `https://<логин>.github.io/kashira-vestnik/`.

Обновление выпусков: снова **Add file → Upload files**, GitHub перезапишет изменившиеся файлы. Публикация обновится автоматически.

## 3. Как задеплоить без аккаунта (Netlify Drop)

1. Открой `app.netlify.com/drop`.
2. Перетащи папку `kiosk` целиком (или её ZIP).
3. Получишь ссылку сразу. Для постоянного адреса понадобится регистрация.

## 4. Технические заметки

- **Все пути относительные** — сайт работает и в корне домена, и в подпапке (`/kashira-vestnik/`). Не заменяй их на абсолютные (`/assets/...`) — на GitHub Pages это ломает ссылки.
- **Имя файла выпуска — строго `index.html`**, иначе по адресу `issues/issue-2/` ничего не откроется.
- **Размеры:** старайтесь держать каждую картинку до ~500 КБ. GitHub отдаёт статику без сжатия, тяжёлые страницы медленно грузятся на телефоне.
- **Регистр имён** имеет значение на сервере: `Cover.JPG` и `cover.jpg` — разные файлы.
- **Проверка перед публикацией:** открой локально корневой `index.html`, кликни карточку выпуска, убедись, что картинки на месте и ссылка «← Киоск» возвращает назад.
- Папка `template/` на сайте тоже доступна по адресу `.../template/` — это нормально, она не мешает. При желании можно переименовать её в `_template`, но тогда добавь `.nojekyll` (он уже есть) либо убери папку из репозитория.

## 5. Если деплоит агент

Агенту достаточно передать доступ (GitHub-токен с правами **Contents: Read and write** и **Pages: Read and write**), либо FTP/панель хостинга. Он создаст репозиторий, зальёт `kiosk/` и включит Pages.
